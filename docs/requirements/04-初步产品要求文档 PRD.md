# 产品要求文档（Product Requirements Document · PRD）

> 本文档整合所有功能需求与非功能需求，是开发与测试的唯一基线。
> 版本：**v1.0（迭代 1 基线）** · 生成日期：2026-11-03

---

## 1. 产品概述

| 项目 | 内容 |
|------|------|
| 产品名称 | 知勤 · 人脸识别考勤管理系统 |
| 产品定位 | 面向小型团队的轻量级人脸识别考勤解决方案 |
| 目标用户 | 系统管理员（HR / 行政人员） |
| 核心价值 | 让考勤从"手工登记 → 自动识别 → 数据可追溯"全链路打通 |
| 差异化 | 全本地化部署、无外部云依赖、纯浏览器即可使用 |
| 迭代版本 | v1.0（核心闭环）→ v1.1（体验增强）→ v1.2（运维增强） |

---

## 2. 功能需求清单（Functional Requirements）

### 2.1 管理员登录模块

| 需求编号 | 需求描述 | 优先级 | 验收条件 |
|----------|----------|--------|----------|
| FR-01 | 管理员通过用户名 + 密码登录 | Must | 输入正确凭证成功登录并跳转首页；错误凭证显示提示 |
| FR-02 | 密码 BCrypt 编码存储 | Must | 数据库中不出现明文密码 |
| FR-03 | 登录态通过 Session 维持，超时 60 分钟 | Must | 无操作 60 分钟后自动退出 |
| FR-04 | API 未登录访问返回 401 | Must | 直接调用 `/api/*` 返回 401 JSON |
| FR-05 | 表单与 API 请求启用 CSRF 保护 | Must | 无 CSRF Token 的 POST 请求返回 403 |
| FR-06 | 支持退出登录 | Must | 退出后跳转登录页，Session 清除 |

### 2.2 人员管理模块

| 需求编号 | 需求描述 | 优先级 | 验收条件 |
|----------|----------|--------|----------|
| FR-07 | 新增人员（工号、姓名、部门、职位） | Must | 工号唯一约束，重复工号拒绝 |
| FR-08 | 人员列表查询 | Must | 返回在职/停用/是否已录人脸状态 |
| FR-09 | 人员启用 / 停用 | Must | 停用后无法继续人脸打卡，历史记录保留 |
| FR-10 | 人脸特征录入（128 维描述符） | Must | 特征向量必须合法（128 维、数值范围、归一化） |
| FR-11 | 人脸重复检查 | Must | 录入时与已有人脸比对，欧氏距离 < 0.5 拒绝 |
| FR-12 | 停用人员禁止录入人脸 | Must | 接口返回错误提示 |

### 2.3 人脸打卡模块

| 需求编号 | 需求描述 | 优先级 | 验收条件 |
|----------|----------|--------|----------|
| FR-13 | 浏览器调用摄像头采集视频 | Must | 允许摄像头权限后自动开启 |
| FR-14 | 本地提取 128 维人脸描述符 | Must | TinyFaceDetector + Landmark68 + RecognitionNet |
| FR-15 | 欧氏距离匹配已录入人脸 | Must | 返回匹配到的人员与距离 |
| FR-16 | 匹配距离 > 阈值时拒绝 | Must | 默认阈值 0.50，可在设置中调整（0.30-0.60） |
| FR-17 | 次优匹配距离差距 < 0.05 时拒绝 | Must | 防止模糊匹配误识 |
| FR-18 | 未录入人脸的人员拒绝打卡 | Must | 返回"未找到可靠匹配" |
| FR-19 | 今日已签到不可重复签到 | Must | 同日 `check_in` 已存在时拒绝 |
| FR-20 | 签退前必须完成签到 | Must | `attendance` 记录不存在时拒绝签退 |
| FR-21 | 今日已签退不可重复签退 | Must | `check_out` 已存在时拒绝 |
| FR-22 | 多人脸 / 无人脸时拒绝 | Must | 返回明确提示 |
| FR-23 | 迟到 / 早退自动判断 | Must | 基于设置的上/下班时间 |

### 2.4 考勤总览模块

| 需求编号 | 需求描述 | 优先级 | 验收条件 |
|----------|----------|--------|----------|
| FR-24 | 今日应到人数统计 | Must | 在职人员数 |
| FR-25 | 今日实际出勤人数 | Must | 今日有签到记录的人数 |
| FR-26 | 今日考勤异常人数 | Must | 状态 ≠ "正常" |
| FR-27 | 今日尚未签到人数 | Must | 应到 - 出勤 |
| FR-28 | 近 7 / 30 天签到趋势图 | Should | SVG 折线图，可切换范围 |
| FR-29 | 今日出勤分布环形图 | Should | 正常 / 异常 / 尚未签到占比 |

### 2.5 考勤记录模块

| 需求编号 | 需求描述 | 优先级 | 验收条件 |
|----------|----------|--------|----------|
| FR-30 | 按日期范围查询记录（最多一年） | Must | 超出一年拒绝 |
| FR-31 | 姓名 / 工号 / 部门搜索筛选 | Must | 前端实时过滤 |
| FR-32 | 状态筛选（正常 / 迟到 / 早退 / 未处理异常） | Should | 下拉选择 |
| FR-33 | 分页展示 | Should | 每页 10 条 |
| FR-34 | 异常考勤核实（附备注） | Must | `note` 字段 1-300 字，标记 `resolved=true` |
| FR-35 | 核实不改变原始状态 | Must | `status` 字段保留原值 |
| FR-36 | 重复核实拒绝 | Must | 已处理记录返回错误 |

### 2.6 统计与导出模块

| 需求编号 | 需求描述 | 优先级 | 验收条件 |
|----------|----------|--------|----------|
| FR-37 | 本月部门出勤分析表 | Should | 部门在职人数 / 出勤次数 / 正常占比 |
| FR-38 | CSV 报表导出（UTF-8 BOM） | Must | Excel 可直接打开中文表头 |
| FR-39 | CSV 公式注入防护 | Must | 字段以 `= + @ - \t \r` 开头时加前导 `'` |
| FR-40 | 导出指定日期范围完整记录 | Must | 不受页面筛选条件影响 |

### 2.7 系统设置模块

| 需求编号 | 需求描述 | 优先级 | 验收条件 |
|----------|----------|--------|----------|
| FR-41 | 上/下班时间可配置 | Must | 格式 HH:mm，下班时间必须晚于上班时间 |
| FR-42 | 识别阈值可配置 | Must | 范围 0.30 – 0.60，超出拒绝 |
| FR-43 | 设置变更仅影响后续打卡 | Must | 历史记录状态保留不变 |
| FR-44 | 默认值：09:00 / 18:00 / 0.50 | Must | 首次启动自动初始化 |

## 3. 非功能需求清单（Non-Functional Requirements）

### 3.1 性能

| 编号 | 需求 | 指标 |
|------|------|------|
| NFR-01 | 人脸特征匹配响应时间 | ≤ 1 秒（排除摄像头采集时间） |
| NFR-02 | 考勤记录查询响应时间 | ≤ 500 ms（一年范围） |
| NFR-03 | 页面首次加载时间 | ≤ 2 秒（不含模型加载） |
| NFR-04 | 人脸识别模型加载时间 | ≤ 5 秒（首次） |

### 3.2 安全

| 编号 | 需求 |
|------|------|
| NFR-05 | 所有写操作启用 CSRF 保护 |
| NFR-06 | 管理员密码 BCrypt 编码 |
| NFR-07 | API 未登录返回 401，不返回敏感堆栈信息 |
| NFR-08 | 人脸特征以 JSON 字符串存入 CLOB，原始照片不上传不持久化 |
| NFR-09 | 默认仅监听 localhost，远程访问需配置 HTTPS |

### 3.3 可用性

| 编号 | 需求 |
|------|------|
| NFR-10 | 浏览器：Chrome / Edge 最新版 |
| NFR-11 | 操作系统：Windows 10/11、macOS、Linux |
| NFR-12 | 分辨率 ≥ 1280×720 |
| NFR-13 | 摄像头：720p 及以上，光线充足 |

### 3.4 可靠性

| 编号 | 需求 |
|------|------|
| NFR-14 | 数据库服务：H2 自动持久化，重启数据不丢失 |
| NFR-15 | 演示数据与真实数据隔离（`demo` 标记） |
| NFR-16 | 关键业务操作（录入、打卡、核实）事务保护 |

### 3.5 可维护性

| 编号 | 需求 |
|------|------|
| NFR-17 | 代码行数：后端核心模块 ≤ 150 行/类 |
| NFR-18 | 单元/集成测试覆盖核心业务流程 |
| NFR-19 | 环境变量配置端口、密码、种子数据等 |
| NFR-20 | 启动脚本一键化（`start.ps1` + `download-models.ps1`） |

### 3.6 边界声明（明确不做）

| 编号 | 边界 | 说明 |
|------|------|------|
| B-01 | ❌ 无活体检测 | 照片/视频重放可伪造，**仅用于受监督演示** |
| B-02 | ❌ 无服务端特征提取 | 完全依赖浏览器 face-api.js |
| B-03 | ❌ 无排班 / 请假 / 节假日管理 | 单班次固定时间 |
| B-04 | ❌ 无员工自助账号 / 角色分权 | 当前仅管理员角色 |
| B-05 | ❌ 无移动端 App | 纯浏览器 Web 应用 |
| B-06 | ❌ 无多租户 / 云端部署 | 单机 H2 文件数据库 |
| B-07 | ❌ 不支持公网直接 HTTP 摄像头访问 | localhost 例外，公网需 HTTPS |
