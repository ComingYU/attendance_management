## 验收标准通用模板

每条 Story 的验收条件遵循 **Given / When / Then** 格式：

```
Story: ST-XX 作为 [角色]，我想要 [功能]，以便 [价值]

验收条件 AC-1:
  Given 前置条件
  When  触发动作
  Then  期望结果 + 具体数据/状态

验收条件 AC-2:
  Given ...
  When  ...
  Then  ...
```
